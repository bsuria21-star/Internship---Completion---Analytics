# Internship Project: Departmental Analytics
## 📌 Project Overview
This project analyzes internship completion rates across different departments to identify processing bottlenecks, streamline onboarding timelines, and provide data-driven insights for management.

## 🛠️ Tools & Technologies Used
* **Data Visualization:** Tableau Public
* **Data Processing & Analytics:** MySQL / Python (Pandas) / Excel 
* **Version Control:** GitHub

## 💡 Key Insights & Findings
* **Insight 1:** Certain departments show significantly higher completion rates due to structured early-stage check-ins.
* **Insight 2:** A noticeable bottleneck was identified during the mid-internship review phase, causing minor delays in overall timelines.
